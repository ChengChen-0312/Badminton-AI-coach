PROJECT SUMMARY
--------------------------------
Badminton-AI-coach is an end-to-end badminton analytics stack:
- Vision: court/ball/player/pose perception
- Geometry: homography + court coordinate mapping
- Tracking + spatial-temporal logic: contact/landing/hitter/stroke reasoning
- Reporting: markdown/json/csv + heatmap/timeline + tactical summary
- Optional AI score: MLX teacher/student feedback and distillation tooling

PPT SNAPSHOT ALIGNMENT (2026-02-12)

- Court lock pass rate: 83.3% (5/6), remaining hard case: Case 05.
- Distillation scale: 835 teacher-labeled videos.
- iOS MVP status: job -> status -> report flow completed via local API integration.
- Near-term direction: keep court robustness improvements while lifting feedback quality (pose-aware + rubric-driven).
